## 一、修：勾了「鼠标穿透」，点击还是被窗口吞掉（issue #24）

**现象**：开透明背景 → 勾「鼠标穿透」→ 点画面任意位置，期望落到下层窗口，实际全被宿主吞掉；
重开窗口（设置持久化）依旧。

**根因有两层，都不在「穿透的判定逻辑」里**：

1. **捕获窗一直待在播放窗下面。** 透明窗口靠一个不可见的「捕获窗」转发鼠标，它必须在播放窗**之上**。
   旧代码却是「先 `BringToFront()` 再 `Show()`」—— 对**还没显示**的窗口，`BringToFront()` 是静默
   无效操作；紧接着全屏几何又用 `TopMost` 把播放窗重新提到最上。于是捕获窗整个生命周期都压在播放窗
   底下、一次输入都没收到，每一次点击都直接落到播放窗的 WebView2 子窗口。这就是「重开窗口依旧」的
   原因：它每次都这样。
2. **热区区域在启动期是「整窗」。** 旧逻辑是 fail-open：穿透开着但页面还没上报热区时，把「无区域」
   传给 `SetWindowRgn` —— 而 `SetWindowRgn(hwnd, NULL)` 是**取消**区域，等于整窗可点。持久化的穿透在
   设置到达时就生效，远早于页面就绪，所以捕获窗从一出生就是整窗。

**现在**：捕获窗用 `Owner` + 显式 `SetWindowPos(HWND_TOPMOST)` 压在播放窗之上，每次几何变化后重新
断言；区域改成 **fail-closed** —— 热区没上报时退到两个角落锚点（右上齿轮、右下圆钮），连锚点都被裁掉
就传一个**空区域**而不是 `NULL`。

日志也补齐了：现在会同时记「页面声称什么」（`hitbox rects=N viewport=WxH`）与「实际变成什么」
（`hitbox apply rects=N`）。这个 bug 之前无法从日志定性，就是因为只有一行 `rects=0` 可看。

## 二、新增：歌词画布的「全局渲染」（issue #22 第 1 条）

Folia 本来就有「歌词画布分辨率 / 抗锯齿」这个全局挡位，但它的控件在上游的「动画与性能」页 ——
那一页没有注入到本插件里，所以**在哪儿都找不到它**（就是你截图里的那两行）。

现在「歌词样式」设置页**顶部**多了一个「**全局渲染**」组：分辨率 `0.5× / 0.75× / 1× / 1.5× / 2×`、
抗锯齿 `自动 / 开 / 关`，17 种样式默认都跟随它。下面各样式自己的「渲染」组仍显示「跟随全局」，
两者正好对应。改动**立刻生效**（不必重开窗口），并且会记住。

> 注意：纯 DOM/CSS 的 6 种样式（流光 / 云阶 / 倾诉 / 回环 / 群唱 / 静止）本来就不按像素密度画，
> 调了不会有变化 —— 它们没有这个参数，不是没生效。

## 三、新增：文字颜色（issue #22 第 2 条）

「歌词样式」→「字体」里多了「**文字颜色**」：`浅色 / 深色 / 跟随系统`。开透明背景时再多一行
「**透明窗口下的文字颜色**」，两者独立。

默认都是「跟随系统」，也就是**原来的样子**（不透明时看封面明暗，透明时跟随系统配色），所以升级
不会改变你现在看到的画面。

只影响**歌词与字幕的文字**，背景与强调色仍由封面决定 —— 否则选「深色文字」会把绘光的暗场、凝彩的
调色底整块翻过去。

## 四、新增：保持屏幕唤醒（issue #22 第 3 条）

「模组管理 → 配置 → 播放页 → **保持屏幕唤醒**」，默认**开**：播放页开着时阻止屏保与显示器休眠，
歌词不会被屏保盖掉。关掉即恢复系统设置。

默认开是刻意的 —— 你报的就是「一段时间不动，屏幕壁纸就被覆盖了」，默认关等于没修。

## 其它

- 修了发布门禁的一个自身缺陷：机器上 `bash` 不在 PATH 时，门禁脚本会以 `TypeError` 崩掉而不是给出
  可读判定。现在直接读目录，不再依赖外部命令。
- 设置项与配置文件格式向后兼容，**升级不会丢设置**；三个新开关都有默认值。
- 更新提示不会重复弹：那条一次性提示属于 0.5.0，本版原样保留判定，日志里能看到
  `update notice: skipped (version=0.5.1 noticed=0.5.0)`。

## 安装

1. 下载 `spw-folia-0.5.1.spmod`；
2. **先删掉旧的同 id 插件**（同 id 多版本不要并存），再导入；
3. SPW → 模组管理 → 启用 → 按提示重启 SPW。

Steam 创意工坊的订阅版会走它自己的更新通道，本预览版需要手动导入。

`.spmod` 的 SHA-256 见 `SHA256SUMS-v0.5.1.txt`。
