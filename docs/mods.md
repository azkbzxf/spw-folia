# 模组系统（Beta）

从官方 [Folium 模组市场](https://folium-compound.cielaniska.top/) 安装社区与官方模组，让它们在这个插件里
生效。**Beta：模组是第三方代码，行为与稳定性由模组作者负责。**

## 这是什么

Folia 本身有一套模组系统（Folium）：模组是一段纯 ESM 的 `client.mjs`，通过 `folium.registries.*`
往宿主里注册新东西 —— 歌词动画样式、播放条按钮、背景、设置卡片等。本插件内嵌的就是 Folia 的
生产 OBS 产物，所以**同一套注册接口在我们这里同样成立**：装一个模组，它的歌词动画就会出现在
「歌词样式」货架上，和 17 种内置样式并列。

## 当前支持范围

| 模组的扩展点 | 状态 | 说明 |
|---|---|---|
| `visualizers`（歌词动画样式） | ✅ 支持 | 装完即出现在货架；可选中、可预览 |
| `progressButtons`（进度条按钮） | ✅ 支持 | `progress.leading` / `progress.trailing` 两个位置，挂到本插件的播放条上 |
| `progressLayers`（进度条图层） | ⚠️ 部分 | 只保留注册与清理，图层本身不绘制 |
| `settingsSections`（模组自己的设置卡片） | ❌ 不支持 | 设置窗里没有模组设置面板 |
| `backgrounds`（背景类型） | ❌ 不支持 | 背景由本插件自己管理 |
| `stageLayers` / `homeTabs` / `playerPanelTabs` / `commands` / `styles` | ❌ 不支持 | 这些属于 Folia 桌面主窗口的界面 |
| Node 入口（`main`） | ❌ 不支持 | 插件里没有 Node 运行时；只有 `client` 入口会被执行 |

模组声明了不支持的权限时**不会**因此装不上，只是那部分功能不生效。

## 怎么用

1. **设置 → 插件配置 → 模组 → 模组市场**。点它会打开 Folia 窗口（没开的话）并直接进入市场；同一组里
   还有「打开模组文件夹」，播放窗口打不开时也能用。
2. 列表分「官方 / 社区 / Beta」三组，可按名称或作者搜索。卡片显示版本、作者、权限数、
   所需 Folia 版本与包大小。
3. 点**安装**。插件下载 zip、核对市场公布的 SHA-256，对不上就丢弃（不会落进模组目录）；
   核对通过才解包到模组目录。
4. 装好的模组默认**立即启用**。选中它的歌词样式即可看到效果（「歌词样式」货架的最后一组）。
5. 卸载 / 禁用也在同一个面板里。

模组目录是插件数据目录下的 `mods/`，市场面板里有「打开模组文件夹」，SPW 配置页的「模组 → 打开模组
文件夹」是同一个目录。手工把解包好的模组文件夹（含 `mod.json`）放进去同样生效 —— 下次打开窗口就会被
扫描到。

## 安全与隐私

- **签名没有在插件里验证。** 市场给每个模组带 `folium.sig.json`，本插件只把它当展示信息，
  不做密码学校验。装上来的代码**没有经过本插件的审查** —— 请只安装你信任的来源。
- 下载只在**你点安装时**发生，请求只发往市场域名；插件不检查更新、不自动下载。
  市场清单（`catalog.json`）由页面自己读取（它有 CORS 头），模组包则一律由插件下载
  （市场对 zip 没有 CORS 头）。
- 模组运行在页面的 WebView2 里。它拿到的能力限于 Folia 的注册接口；`folium.playback`、
  `folium.omni`、`folium.equalizer` 这些需要宿主适配层的接口在本插件里**不可用**（调用会抛错）。
- 模组**不能**访问文件系统：`folium.storage` 在本插件里是空实现（读回 `undefined`），
  写不落盘。所以「记住设置」这类模组功能不会持久化。

## 已知边界

- 装好的模组**改不了本插件的设置**；它只增加歌词样式与进度条按钮。
- 卸载或禁用正在使用的模组后，画面会回落到内置样式。设置窗的货架会明确标出
  「所选的模组样式已不可用」，不会静默改变你的选择。
- 模组不影响「随机歌词样式」的随机池：随机只在 17 种内置样式里挑。
- 模组样式**不支持**透明窗口（色键）下的合成 —— 它按内置样式的保守策略当作不可适配。
- 第一次安装某个模组时，模组作者可能要求特定 Folia 版本；不满足时面板会标出来，但仍允许安装。

## 排障

- **装完货架上没有新格**：确认模组包里有 `mod.json` 与 `client.mjs`，且 `mod.json` 的 `id`
  符合 `^[a-z0-9][a-z0-9-]*$`（小写字母、数字、连字符）。面板里的「打开模组文件夹」可以直接看。
- **选中模组样式后画面是内置样式**：说明模组的 `client` 入口没跑起来。日志里有
  `[spw-folia] mod … failed` 一行；把日志与模组 id 一起反馈。
- **画面只有底噪、没有字**：模组可能用了本插件未实现的接口。同上，附日志反馈。

完整实现与契约见 [`docs/mod-system.md`](mod-system.md)。
