# v0.5.2 · Beta 模组系统（issue #23）

这一版把官方 [Folium 模组市场](https://folium-compound.cielaniska.top/) 接进了插件：装一个模组，
它的歌词动画就和 17 种内置样式一起出现在「歌词样式」货架上。

**这是 Beta。** 模组是第三方代码，本插件不会审查它 —— 请只安装你信任的来源。

## 新功能

- **模组市场（Beta）** —— 播放页右下角按钮面板里多一行「模组市场（Beta）」。打开就是官方市场的
  全部模组：官方 / 社区 / Beta 三组，可按名称或作者搜索。每张卡片给出预览图、版本、作者、
  所需权限数、要求的 Folia 版本与包大小。
- **一键安装** —— 点「安装」后插件下载 zip、**核对市场公布的 SHA-256**（对不上就丢弃，绝不落进
  模组目录），核对通过才解包。装好的模组默认立即启用。
- **歌词动画模组生效** —— 模组注册的歌词样式以 `mod:<模组 id>:<样式名>` 出现在货架最后一组。
  选中即可播放、预览。货架格显示的是模组自己的 `preview.jpg`。
- **模组进度条按钮** —— 模组可以往播放条的左侧 / 右侧加按钮（这两个位置的数据来自 Folia 的
  `progressButtons` 注册表，由本插件转发给自绘播放条）。
- **管理与卸载** —— 同一面板里能启用 / 禁用 / 卸载，也能「打开模组文件夹」手工放模组进去
  （放进去的目录含 `mod.json` 即会在下次扫描时出现）。
- **选中的模组样式被卸载时会明说** —— 设置窗的货架会标出「所选的模组样式已不可用」，
  而不是静默把画面换成内置样式。

## 已修 / 已加固

- **旧名兼容层必须打开，否则模组「装好但不显示」**：Folium 2 的 mount 上下文去掉了
  `ctx.currentTime` 与 `ctx.subscribe`，而市场上绝大多数模组仍在使用它们。不补这层的话，
  模组会注册成功、挂上外壳、**一个字都画不出来**。开发期实测 `spans: 0`（一个字符都没有），
  补上之后 `spans: 5`、`"光が満ちて"`。门禁现在断言的是**画出了字**，不是「外壳存在」。
- **停用模组要真的停住**：模组通过 `api.every()` 起的定时器、`api.onDispose()` 注册的清理
  都必须在停用时执行，否则禁用之后它还在后台跑。现在按上游的顺序逐项执行。
- **模组文件走独立虚拟主机**（`spw-folia-mods.local`）。`SetVirtualHostNameToFolderMapping`
  对同一主机的优先级高于 `WebResourceRequested`，所以最初设想的「在 bundle 主机下加
  `/__mods/`」在真机上**一次都不会被拦截**，症状与「文件不存在」完全相同。改用独立主机 + CORS
  后跨源 `import()` 正常工作。
- **目录穿越防护**：`/__mods/../../index.html` 与编码变体全部 404，有门禁断言。

## 还没做的（明确记录）

| 能力 | 状态 |
|---|---|
| `settingsSections`（模组自己的设置卡片） | 不支持 —— 设置窗没有模组设置面板 |
| `backgrounds` / `stageLayers` / `homeTabs` / `playerPanelTabs` / `commands` / `styles` | 不支持 —— 属于 Folia 桌面主窗口界面 |
| Node 入口（`main`） | 不支持 —— 插件里没有 Node 运行时 |
| `folium.sig.json` 签名校验 | **只展示不验证**，UI 明确标注 |
| `folium.storage` 持久化 | 空实现（读回 `undefined`），模组记不住设置 |
| 模组样式进随机池 | 不支持 —— 随机只在 17 种内置样式里挑 |
| 模组样式 + 透明窗口 | 不支持 —— 按内置样式的保守策略当作不可适配 |

## 验收（本版做了什么、没做什么）

**做了**：`node packaging/tools/verify-mod-market.mjs` → **20/20 通过**（打包清单 + 真宿主文件服务
+ 目录穿越 + 真机激活并画出字）；`verify-all.mjs --static` → 6/6；`verify-select-layers` 11/11；
`verify-click-zones` 56/56；`verify-diagnostics` 16/16；`verify-layout` PASS；JVM 单测 36 项新增
（真实 zip 解包 / 目录穿越 / sha256 不匹配 / 多一层目录），全量 110 项通过；
`poc/settings-ui` 的 `vite build` 与 tsc 基线（310）不变。

**没做**：真实 SPW 安装里的端到端冒烟（需要装上插件并播放音乐），以及「从市场真的下载并安装
一个第三方模组」的联网验收 —— 后者由单元测试（默认跳过）与手工命令覆盖，见
[`docs/mod-system.md`](mod-system.md)。

## 兼容性

- 要求不变：Windows 10/11 x64、Salt Player for Windows **1.19.0 及以上**、WebView2 Runtime。
- 内嵌上游 Folia **0.7.26**、Folium **1.8**。
- **首次引入运行时网络请求**：只有两处 —— 页面读取市场 `catalog.json`（你打开市场面板时），
  以及插件在你点「安装」时下载那个 zip。其余时间插件完全离线。
