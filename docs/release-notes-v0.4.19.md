# v0.4.19 更新日志

本次版本跟进上游 **Folia 0.7.26**（321 次提交），把歌词样式与字幕的设置对齐到上游：所有样式的
**默认值**重新与上游一致，多款样式的观感同步更新，字幕新增「副字幕行数 / 内容」并补齐了它背后
整条链路。

## 1. 跟进上游 Folia 0.7.26

内嵌的 Folia 由 **0.7.25** 换成 **0.7.26**，仍是 **17 种**歌词样式（这一版没有新增或删除样式）。

换库不是「把产物拷进来」就完事：设置页直接用 Folia 自己的 React 组件，两边类型一错就白屏。这次
逐项核对下来，0.7.26 对我们有实际影响的变化是这些：

- **每款样式的默认值都重新对齐上游**。样式参数（tuning）的默认值一律从上游
  `DEFAULT_*_TUNING` 引用，不在这里另抄一份；这一版新加的键（见下）因此自动跟随。
- **观感更新**：上游在 0.7.26 里重做／调整了多款样式的画面 —— 町景的辉光与灯光、雾笺的窗外与
  玻璃、以及绘光 / 凝彩 / 莫奈 / 时计等一批细节。这些是渲染器自己的改动，插件原样承接；设置页的
  17 张样式小图与宣传站图因此**全部重采**，与实机一致。
- **「心象」第一次有了设置面板**。上游给它补了参数（此前它是 17 款里唯一一款完全没有参数的
  样式，设置页只能显示空态）。
- 样式清单的机械部分（构建闸门的 id 列表、缩略图采集列表、宣传站采集列表、宿主 HUD 列表）由
  `scripts/check-style-sync.mjs` 与上游源码逐字核对，`vite build` 会在不一致时直接失败。

## 2. 新增「分辨率 / 抗锯齿」，默认跟随全局挡位（上游 #929）

上游给每款用 canvas / WebGL 画的样式加了两行「**渲染**」设置：

- **分辨率**：`0.5× / 0.75× / 1× / 1.5× / 2×`，或「**跟随全局**」（默认）。
- **抗锯齿**：开 / 关，或「**跟随全局**」（默认）。全屏着色器类样式与 2D canvas 样式只给分辨率
  一行 —— 它们没有 MSAA 可言，给一个不生效的开关不如不给。

默认「跟随全局」等于各样式原来的样子，所以**升级后观感不变**，只有主动调低才降画质换流畅。

> 上游把全局挡位放在「动画与性能」页，那一页不在本插件注入的设置窗口里。本插件的样式面板只显示
> 「跟随全局」即当前全局值是多少（说明文字里写着），没有单独调全局的入口 —— 保持默认即可。

## 3. 字幕：副字幕行数 / 内容（已可用）

v0.4.17 那一版**移除了**这个控件：上游 0.7.25 新增它时要求一个本插件没有的设置项
（`subtitleOverlayLayout`），而组件内部对它**没有默认值**，直接渲染会让「字幕」tab 抛异常、
整个设置岛白屏（设置岛没有 ErrorBoundary，一个组件炸掉就是整片白）。

这一版把**整条链路补齐**，控件恢复：

- 设置树新增 `subtitleOverlayLayout`，默认 `translation`（与之前的 `subtitleContentMode`
  行为一致），随设置一起持久化、导入导出、跟随插件配置同步；
- 「字幕」tab 里可以选 **1 / 2 / 3 行**，并逐行选这一行显示什么：当前歌词 / 下一句 / 译文；
- 选择会真正**发给播放页**（随 `ObsBrowserSourceConfig` 一起下发），底部字幕按所选行渲染 ——
  不是只在设置页里存着。

**罗马音选项仍然不提供**：插件的歌词数据只有正文、副文与逐字时轴，没有罗马音（
`FoliaPlaybackExtension.lyricsJson()` 只输出 `main` / `sub` / `cells`）。留一个永远渲染不出内容的
选项就是撒谎，所以它跟 v0.4.17 时一样不出现。

## 4. 修掉一个一直失败的重采脚本

`poc/settings-ui/scripts/make-thumbs.mjs --force`（重新采集 17 张样式小图）**从 v0.4.13 起就是坏的**：
某次重构把截图落盘路径改成了 `<style>.L<行>.<次>.png`，但校验代码还在检查旧的 `<style>.png`，
于是**每次采集成功后都抛「no usable screenshot」**。之所以一直没人发现，是因为脚本默认只补**缺**的
小图，而 17 张早就在本机存在了 —— 只有 `--force` 才会踩到。

现在校验改成检查真实产出的候选帧，`--force` 能正常跑完。本版 17 张图就是用它重采的。

## 验证

- **设置页**：`node scripts/check-style-sync.mjs --check` 与上游源码零差异；`vite build` 通过
  （含缩略图硬闸与全部手术标记）；`tsc --noEmit` 不高于新基线；四个 tab 逐个点开、多个样式面板
  逐个打开，均无白屏。
- **字幕**：在 Node 里构造一遍发布配置，断言 `subtitleOverlayLayout` 确实在载荷里；改行数/内容后
  播放页底部字幕随之变化。
- **样式小图**：17 张逐张肉眼核对（拼成一张对照表看的），每张都能认出是哪个样式且至少有一行清晰
  可读的歌词；`still` 这类极简样式按既有标准豁免。
- **发布门禁**：`node packaging/tools/verify-all.mjs` 全部通过。

## 说明

- 本次**没有**新增或删除歌词样式，仍是 17 种；`v0.4.17` 起的入口、快捷键、透明背景、点画面分区、
  播放控制等行为不变。
- 上游 0.7.26 的其他改动（外部播放器 Stage API、Apple Music 支持、速记簿、搜索重做、全局快捷键
  等）属于 Folia 桌面应用自身功能，与本插件无关 —— 插件只内嵌它的**歌词可视化页面**。
