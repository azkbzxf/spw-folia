# spw-folia v0.4.14 更新日志

> **这是 v0.4.13 的修复版。** v0.4.13 当天发布后又被下架了，原因见下面第一节。
> 如果你从没装过 v0.4.13，那这版对你来说就是「v0.4.6 之后所有改动的完整合集」，
> 直接看第二节开始的内容即可。

---

## 一、先说清楚：v0.4.13 为什么被下架

v0.4.13 要做的事是**修好三个配置开关**，这件事它做到了。但同一个版本里还加了一段
「读不到配置文件就重试一次」的逻辑，写成了**无限递归**。

触发它的条件很普通：**你刚装上插件、还没打开过配置页**，此时配置文件都还不存在。
一旦命中，插件会在这个循环里打转，把播放器的界面卡死，最后被系统判定为
「界面持续无响应」并强制结束进程。我在自己机器上复现到了：卡了 **9 分 13 秒**，
递归 **1450 次**。

所以 v0.4.13 被下架，**这个版本（v0.4.14）把它修好了**。
我在同一台机器、同样的条件（配置文件都不存在）下重新验证过：
只写一行日志、直接使用默认值、启动继续完成、播放器正常。

> 完整的技术复盘写在 [`postmortem-v0.4.13.md`](postmortem-v0.4.13.md)。

## 二、修好了三个开关（v0.4.13 原本的目标，保留了）

之前有一版把配置页的三个开关弄坏了：**开关打开了，但功能没反应**。

| 开关 | 现在的效果 |
| --- | --- |
| 打开过渡动画 | 打开 Folia 时有开屏动画 |
| 显示播放条 | 播放页底部有播放控制条（时间轴 / 播放暂停 / 上下首 / 随机 / 播放列表） |
| 显示问题反馈按钮 | 播放页右上角出现救生圈按钮 |

现在三个都正常，而且**改了立刻生效**，不用关掉窗口再重开。

> 其中「打开过渡动画」和「详细日志」是下次打开 Folia 时才生效的，因为它们决定窗口怎么被打开。

## 三、这一版额外修掉的几个「看着没事、其实会咬人」的问题

这些是复盘 v0.4.13 时顺手在别处查出来并修掉的，都属于「平时不发作、一发作就很难查」的类型：

### 1. 「出现问题」自检曾经会在健康电脑上乱报错

如果你的电脑位数读不出来（某些精简系统会这样），自检会直接报
**「当前不是 64 位系统」** —— 一个硬错误。而实际上它只是没读到信息。

现在改成三态：读到了 → 正常判断；确实 32 位 → 报错（这才是真的跑不了）；
**读不到 → 显示「无法判定」**，不再假装你的电脑有问题。

### 2. 自检里的系统查询可能把界面卡住

自检要调用 Windows 的 `reg.exe` 读注册表，原本写了个 3 秒超时，但**那个超时其实永远不会生效**
（它等数据读完之后才开始计时）。如果杀毒软件拦截了 `reg.exe`，界面就会一直卡着。

现在超时是真的了。

### 3. 一个设置可能「看着存了、其实没存」

保存设置时如果宿主返回失败，代码仍然把它记成「已保存」，然后不再重试 ——
结果是这次改动静默丢失。现在失败会重试。

## 四、两个新歌词样式（15 → 17）

跟着上游更新一起加进来的：

- **町景** —— 三维微缩街景，歌词写在便利店 LED 屏和招牌上。有便利店 / 车站 / 城寨三套场景，
  时间、天气、镜头都能调。
- **雾笺** —— 雨夜公交车上起雾的车窗，歌词按笔顺一笔一笔写出来，写过的笔画露出窗外夜景，
  水珠顺着笔画淌下来。

## 五、开屏动画换成了原版的

之前是我们自己做的一段过渡动画（封面取色渐变、极光、余烬、光扫那一套），
现在换成 **Folia 原版的开屏**：深色底 + 居中发光的「Folia」字样 + 一排随机跳动的波形竖条。

顺便修了两个问题：
- 原来开屏会多停留约 1 秒，现在准时消失；
- 开屏上的字原来会随机换字体，看着像坏掉了，现在固定一种。

## 六、透明模式不再一片粉

如果你用过「透明播放器背景」，可能见过画面上糊一层**粉色**。

原因不是背景色选错了，而是透明模式下那些**半透明的地方**（比如字的边缘）会被染色。
换了一个几乎看不见的底色之后，粉色彻底消失了。

## 七、配置页重新整理了

以前配置项混在一起，现在按「你什么时候会用到它」分成三组：

| 分组 | 放什么 |
| --- | --- |
| **播放页** | 打开过渡动画、显示播放条、显示问题反馈按钮 |
| **诊断与日志** | 详细日志（平时不用开，排查问题才用） |
| **支持与反馈** | 出现问题（打不开播放窗口时也能用） |

新增的「显示问题反馈按钮」**默认是关的**，因为它会挡在画面右上角。

## 安装 / 升级

1. 下载 `spw-folia-0.4.14.spmod`；
2. 放到 `%APPDATA%\Salt Player for Windows\workshop\plugins\`；
3. 打开 SPW → 模组管理 → 启用。

**如果你装过已下架的 v0.4.13，先把它删掉再装这个** —— 同 id 的两个版本不要并存。

**升级不会丢设置。** 之前的设置会自动迁移过来，包括「详细日志」这种挪过位置的开关。

## 附：这一版是怎么验证的（给想了解的人）

上一版之所以「门禁全绿却翻了车」，是因为门禁**从来没执行过那条出错的代码路径**。
这一版把门禁补成了这样：

- 门禁从 10 项扩到 **18 项**；
- 新增 **46 个单元测试**，其中 9 个专门盯「配置文件缺失 / 为空 / 被截断」这几条失败路径；
- 新增 4 条**卡死守卫**，静态检查「配置同步绝不允许自我递归」「重试上限必须是常量」等；
- 3 个原本写好了、但**从未被接入门禁**的回归脚本，接进去了；
- 修掉了一条**恒真断言**（写着检查四个状态，实际上永远不会失败）；
- 修掉了一条依赖「开发者本机恰好装过插件」的用例（换台机器就崩溃）。

最关键的验证：把旧版的递归逻辑临时改回去，新加的测试会立刻以
`StackOverflowError` 失败。**测试抓得住这个 bug，才算真的修好了。**
