# spw-folia v0.4.16 更新日志

> 这版只做一件事：**让「歌词样式」面板打开更快，并且在弱机器上可以彻底关掉小图动画。**
> ① 每格样式小图第一次画完会**留到本机**，重启后直接显示，不再每次重新加载；
> ② 配置页新增开关「歌词样式预览动画」，默认开启，关掉后每格只显示简约图案、不加载任何渲染器。

---

## 一、优化：样式小图缓存到本机，第二次打开不再重新加载

### 现象

打开设置 →「歌词样式」，右边是 17 个样式的小图网格。**每重启一次播放窗口，这些小图都要重新画一遍**，
画的过程中整页会明显卡顿。这是设置页面第一次打开慢的主要原因。

### 原因

每格小图不是一张预制图片，而是**用该样式真实的渲染器现场画出来**再冻结成静态图的（这样小图
才能和播放页完全一致）。画一格要拉起那一个样式的整个渲染器 chunk；而它的缓存只存在**当前页面
的内存里** —— 播放窗口一关，页面一销毁，缓存就没了，下次进来 17 格全部重画。

### 修复

第一次画完之后，把冻结好的静态图**留在本机**（浏览器的 IndexedDB，库名 `spw-folia-preview`）。
下次打开设置窗口，先把这些图直接贴出来，**不排队画图、不加载任何样式渲染器**。
只有你把鼠标停在某一格上时，那一格才会挂载真实渲染器跑起来 —— 这个交互一点没变。

缓存键覆盖了一切会影响画面的输入（样式、主题、字号、该样式的调参、窗口尺寸……），任何一项变了就
当作没缓存、重新画一次。缓存有上限（32 条 / 8 MB），超了淘汰最旧的；读写失败一律静默回落到现场画图，
不会让你看到空白格子。

**顺带修了一个真缺陷**：冻结出的静态图里有少数样式（群唱）的 CSS 逐字淡入动画**没有被一起冻结**
（它在冻结那一刻已经播完了，所以没被清理），挂回页面后会从头重播一遍。现在落盘前会统一剥掉，
恢复出来的图是**真静态**的。

### 实测（1920×1200，真机 WebView2 宿主）

| 场景 | 改动前 | 改动后 |
| --- | --- | --- |
| 第一次打开设置（17 格画完） | 24.3 s | 23.2 s（无退化） |
| 同一页面关掉再打开 | 0.05 s | 0.04 s（无退化） |
| **重启播放窗口后再打开** | **23.0 s** | **0.37 s（约 62 倍）** |
| 重启后是否又重新画图 | 是（峰值 1 格在画） | **否（0 格）** |
| 重启后新加载的样式渲染器 | 19 个 | **0 个** |
| 打开设置时主线程最长阻塞 | 1.77 s | 同（首次仍需画一轮，见下） |

> 注意：**第一次**打开仍然要画一轮（约 23 s 是这台机器的实测，期间可以正常操作，只是小图逐个出现）。
> 缓存改善的是**之后每一次**。第一次要不要等，取决于第二节那个开关。

## 二、新增：配置页开关「歌词样式预览动画」（默认开启）

位置：SPW「模组管理 → 配置 → 播放页 → 歌词样式预览动画」，落盘 `config.json`，**默认开**。

- **开启（默认）**：和以前一样，每格是真实渲染器画出的动画小图，鼠标停留会跑起来；第一次画完后
  缓存到本机，之后每次打开直接显示。
- **关闭**：每格只显示一个**简约图案**（每个样式自己的线性字形，和随机格上那个图标同一套），
  **一个样式渲染器都不会加载**，不占显存、不起动画循环。打开设置明显更顺，代价是看不到小图动画。

开关**切换即时生效**，不用重开窗口。

### 实测（关闭时）

| 指标 | 结果 |
| --- | --- |
| 打开设置新加载的样式渲染器 | **0 个** |
| 页面里的图片/画布节点 | **0 个** |
| 鼠标悬停在格子上 | 仍然 **0 个**（不会偷偷加载回来） |
| 大预览、各 tab、滑块 | 全部正常，不受影响 |
| 页面报错 | 0 |

关闭路径是在**模块加载层面**断掉的（那份「实时小图」代码根本不会被下载），不是画了之后藏起来 ——
所以它省的是真的内存和 CPU。

## 三、其它

- 「显示问题反馈按钮」「显示播放条」两条开关的行为不变；本版新增的开关与它们走同一条链路
  （插件读配置 → 设置树顶层布尔 → 页面只读），页面不会回写、不会出现「两个写入方」。
- 门禁新增一组真机验收（`verify-preview-animation-switch.mjs`，37 条断言），覆盖：
  默认开启时照常出图、关闭时零渲染器加载、**跨进程**缓存命中、热切换双向、同页重开不退化。
  另外修掉了一条会误报的门禁断言（它把开关白名单写成了字面量，且名字绑死在旧版本号上）。

---

## 安装 / 升级

覆盖安装即可。**升级后第一次打开设置仍会画一轮小图**（本机还没有缓存），从第二次开始就是秒开。
如果你在弱机器上、不在意小图动画，建议把「歌词样式预览动画」关掉。

旧版本留下的设置不受影响：本版只新增了一个开关键（默认开启），没有改动任何已有的键或存储位置。
