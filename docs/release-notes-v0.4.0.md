# spw-folia v0.4.0 — 花火样式、随机样式池、自定义字体、托盘入口、透明快捷键、打开过渡动画

v0.4.0 是一次**内容 + 体验**更新：web bundle 换成上游 Folia **0.7.22**，带来第 15 种歌词样式
「花火」；同时补上随机歌词样式池、自定义字体（导入字体包 / 系统字体）、字体栏预览默认显示当前
歌词，以及最小化托盘图标的 Folia 入口；播放页透明背景也接进了 SPW 的快捷键管理，可以绑成自己的
快捷键。这一版还新增了从封面取色的打开过渡动画、非透明模式下的左上角退出按钮，并修掉了一批真机
验收中发现的问题（启动粉紫闪屏、预览框一直转圈、预览字体不跟随、托盘入口不显示 / 点了不关闭）。
issue #9 的启动成功提示噪音也在这一版移除；PR #10（多屏跟随、Alt 跨屏拖动、呼出快捷键可配置）
一并合入。

## 重点

- 上游 Folia 0.7.22：新歌词样式「花火」
- 随机歌词样式池 + 每首歌换一种 + 骰子重抽
- 自定义字体（导入字体包 / 系统字体），字体预览默认显示当前歌词，预览框字体实时跟随
- 托盘右键 Folia 入口（与「桌面歌词」同组，点击即开 / 关）
- 播放页透明背景快捷键两条（默认 Ctrl+Alt+G / Ctrl+Alt+Shift+G）
- 打开过渡动画：封面取色、透明→不透明淡入、默认关闭（配置页开关）
- 播放页左上角退出按钮（非透明模式）
- 修复：透明模式下打开时的粉紫闪屏、"正在连接 Folia"预览框、预览字体不跟随、托盘入口缺失

## 新增 / 变更

- **上游 Folia 0.7.22 适配** —— `poc/webview/dist/dist` 里的 web bundle 由 Folia **0.7.21** 换成
  **0.7.22**，取自 `Folia-Setup-0.7.22.exe`，未做修改。
- **新歌词样式「花火」（hanabi）** —— 第 15 种样式：日系歌词 PV 画风，歌词带色块逐字出场，烟花
  沿字开花，镜头之间随升空烟花旋转上升，副歌亮起辉光；注册在 Folia 的 order **26**，即绘光
  （lumiere，25）与流光（classic，30）之间；设置页复用 Folia 自己的 `HanabiSettingsPanel`，缩略图
  `poc/settings-ui/public/thumbs/hanabi.jpg`。
- **随机歌词样式池** —— 「歌词样式」里可把 15 种样式的任意子集勾进随机池；打开「每首歌换一种」后
  每首歌从池里抽一种且不连续重复；播放面板上的骰子按钮可当场重抽。随机池随设置快照保存。
- **自定义字体** —— 字体栏新增「自定义」磁贴，两条路都通：
  1. **导入字体包**：`.ttf` / `.otf` / `.woff` / `.woff2`，单个 ≤ 50 MB，存进 IndexedDB 并用
     `FontFace` 注册；
  2. **系统字体**：插件侧用 AWT 枚举字体家族，注入设置树的 `systemFonts`（最多 400 个家族）。

  字重也一并恢复，选完字体可以继续调粗细。
- **字体预览文本默认 = 当前播放歌词** —— 预览文本新增「当前歌词」选项并作为默认值，字体预览直接
  渲染正在播放的那一行；空闲时回退到内置示例歌曲。随包的两首占位歌曲仍然可选。
- **字体预览跟随（修复）** —— 设置页的「在线歌词预览」是嵌入的同源 iframe；此前导入字体只在播放器
  主文档注册，iframe 文档里没有对应 `FontFace`，所以预览始终回退系统字体。现在打开设置页时会把
  已导入字体的字节注入预览 iframe 文档（在首次下发 config 之前完成，避免 Folia 渲染器不重排），
  新导入字体也会再次注入并重发 config 触发重排；iframe 重新加载时自动重新注入。
- **托盘菜单 Folia 入口** —— SPW 最小化到托盘后，右键图标即可看到 **Folia**，位于「桌面歌词」之后、
  同一分组内；点击是**切换**：窗口没开时打开，已经打开时关闭。
  实现上除了 compose 层的菜单录制 hook，还增加了一层**确定性原生补丁**：hook
  `WindowsTrayMenuBuilderImpl.build()` 在返回的原生菜单项里强制插入 Folia 行，并在托盘管理器就绪后
  主动刷新一次原生菜单 —— 这样不依赖 compose 的重录制时机。
- **播放页透明背景快捷键** —— SPW「快捷键管理」新增两条可重绑动作：
  - `播放页透明背景：开 / 关`（默认 **Ctrl+Alt+G**）：切换透明背景；关闭时一并把「鼠标穿透」复位。
  - `播放页透明背景 + 鼠标穿透：开 / 关`（默认 **Ctrl+Alt+Shift+G**）：两者都关时一起打开，已经
    全开时一起关闭。

  窗口开着时按下立即生效：插件改设置树 → 宿主套色键 → 页面用**自己**的样式兼容表校验（`monet`、
  浅色主题下的 `lumiere` 等不支持透明的样式会拒绝并回退，此时提示「当前歌词样式不支持播放页透明
  背景」）；窗口没开时只写设置，下次打开直接以该模式启动。宿主原有的全局 **Ctrl+Alt+B** 逃生热键
  保持不变；两条默认键位避开了宿主热键链（Ctrl+Alt+B / Y / P / Shift+B）和本机已被占用的
  Ctrl+Alt+T。要让快捷键在 Folia 窗口聚焦时也生效，需要打开该动作的「全局」开关。
- **打开过渡动画（新）** —— 每次打开 Folia 都播放，不区分普通 / 透明 / 鼠标穿透模式：
  - 颜色从**当前歌曲封面**提取（HSV 聚类，最多 4 色；封面不可用时回退内置紫 / 粉 / 青 / 琥珀）；
  - 深色夜幕 + 极光光晕 + 漂浮火星 + 斜向扫光，居中 `Folia` 字样，第二行「让歌词成为风景」使用
    封面色的**左→右渐变**；
  - 动画从**透明到不透明**淡入，固定 **0.8 秒**；页面首帧就绪后淡出露出歌词页（整体时长受
    WebView2 冷启动约 1.5–2 秒影响）；
  - 多屏 / DPI 适配：按窗口所在显示器的物理边界摆放，并按该显示器 DPI（本机 180%）缩放火星半径、
    文字粗细、细线等固定像素元素；
  - 配置页开关「打开过渡动画」，**默认关闭**；开关切换即时生效（下一次打开起）。
- **播放页左上角退出按钮** —— 未开启「播放页透明背景」时，播放页左上角显示圆形 `×` 按钮（与右上角
  设置齿轮严格对称、同样的玻璃质感与淡出行为），点击即关闭 Folia 窗口；透明模式自动隐藏。
- **PR #10：多屏跟随、Alt 跨屏拖动、呼出快捷键可配置** —— 已随本版合入（squash 为 `b30df5d`）。
- **安装包体积优化** —— 发布产物从首个预览版的 **20.0 MB 降到 12.2 MB**（−39%，比 v0.3.1 的
  12.4 MB 还小一点），主要做了两件事：
  - 设置页资源去重：`web/settings/assets/` 里与 `web/assets/` 逐字节相同的 29 个图片（4.00 MB）不再
    重复打包，引用改写成 `/assets/…`；设置岛（注入的设置页）改为从 bundle 同源加载，根绝对路径
    `/assets/…` 才能正确解析；
  - 图片重压缩：插图 / 头像改为 256 色调色板 PNG，预览封面改为 progressive JPEG（`packaging/image-overrides/`
    + `apply-image-overrides.mjs`），4.67 MB → 1.39 MB；文件名与格式不变，所以不需要改任何动态资源 URL。
  - 抵消项：上游 0.7.22 的 web 资源本身比 0.7.21 大 0.47 MB，插件类 +0.12 MB，宿主 +17 KB。
  - 未压缩 staging 仍是 25.97 MB（主要是文本 JS，压缩进 zip 后只有 12.2 MB）；`size-report.json`
    的 25 MB 预算仍是历史防膨胀阈值，现处于 OVER 状态，注释见 `docs/release.md`。

## 修复

- **透明 / 穿透模式打开时的粉紫闪屏** —— 宿主不再使用 WinForms `TransparencyKey`（它会重建窗口句柄并
  闪一帧未上色键的洋红底色），改为直接用 Win32 分层窗口 API（`WS_EX_LAYERED` +
  `SetLayeredWindowAttributes(LWA_COLORKEY)`），并在设置洋红背景色**之前**装好色键。
- **过渡动画只在部分模式可见** —— 遮罩窗口与播放器窗口同为 TopMost，播放器后显示会盖住遮罩；现在在
  窗口创建 / 显示 / 激活时都把遮罩重新置顶，普通模式同样能看到完整动画。
- **「正在连接 Folia」预览框** —— 开发安装的 bundle 曾直接拷贝原始 dist，其中 PWA 的 `sw.js` 会把
  `/preview.html` 导航拦截回 `index.html`，导致预览 iframe 停在 OBS 连接占位页；现在本地安装也统一
  经 `packaging/tools/stage-web.mjs` 生成 `preview.html` + `_host/preview-shim.js`（新增 gradle
  `stageDevWeb` 任务），并清理了旧的 service worker 缓存。
- **修改字体后预览框不跟随** —— 见上文「字体预览跟随」。
- **托盘右键看不到 Folia** —— 见上文「托盘菜单 Folia 入口」的原生补丁。
- **托盘点 Folia 无法关闭** —— 托盘条目改为切换开关。
- **动画时长设置无实际效果** —— 打开时长受 WebView2 冷启动主导，滑杆差异不可感知；按验收反馈**删除
  时长设置**，动画固定 0.8 秒，配置页只保留开关。
- **issue #9：启动不再弹成功提示** —— 只有失败才提示。

## 安装 / 升级

1. 关闭 Salt Player for Windows。
2. mod 管理器里删除旧版 `spw-folia`，导入 `spw-folia-0.4.0.spmod`。
3. 授予 `class-transform`、`library-read` 与 `key-bindings`（快捷键；漏授可在插件权限页补授后重启）。
4. 重启 SPW，`更多 → Folia`；最小化后右键托盘图标也能看到 **Folia**（点击开 / 关）。
5. 透明快捷键在 SPW 的「设置 → 快捷键管理」里（`播放页透明背景：开 / 关`、
   `播放页透明背景 + 鼠标穿透：开 / 关`），需要时打开对应动作的「全局」开关。
6. 过渡动画开关在 `模组管理 → spw-folia → ⋯ → 配置 → 播放页 → 打开过渡动画`（默认关闭）。

可直接覆盖升级 v0.3.1（协议与设置格式均未变；web bundle 换成了 Folia 0.7.22）。

## 已知限制

- **智能动感模式（smart beat）本身仍然不可用**：注入页没有节拍分析模型，宿主也从不发 `beat` 事件。
  因此「花火」的随拍开花 / 推镜、`sonnet` 的推镜、`diorama` 的涟漪这些**节拍驱动**的效果保持静止；
  花火其余效果（逐字色块、烟花开花、镜头升降旋转、副歌辉光）正常。
- **系统字体列表不持久化**：每次启动重新枚举（最多 400 个家族），不写进设置树；导入的字体包存
  IndexedDB，设置树里只记家族名 / 标签。
- **打开总时长受 WebView2 冷启动限制**：约 1.5–2 秒，过渡动画固定 0.8 秒淡入，先遮住加载过程再露出
  页面。
- 其余限制与 v0.3.x 相同：全屏跟随播放器所在显示器、色键透明（键色仍为 `rgb(255,0,255)`）。
